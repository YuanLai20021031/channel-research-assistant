# AI Assistance and Author Contributions

This project was developed with assistance from Codex. It is not presented as entirely handwritten or independently implemented.

## AI-assisted work

Codex helped analyse the assignment, select a Flask and SQLite approach, generate most of the backend, HTML, JavaScript, automated tests and documentation, locate public examples of potential channels, integrate Tavily, read local API credentials safely, validate commands, and package the submission. An additional editing pass converted repository-facing text and sample content to English.

## Author's direct involvement

I supplied my undergraduate Flask booking project as experience and background, asked for the new project to be kept separate, provided the Tavily search configuration, and interacted with the running web interface. I tested different customer and product briefs, including scenarios involving NVIDIA, marketing agencies and software development teams. Through screenshots I reported cases with only one link, no results, or unsuitable recommendations. I also explored the backend request flow and the roles of APIs and the database.

These observations identified weaknesses in the current selection logic. The included prototype does **not** claim those relevance problems have been solved. AI-generated code and AI-executed tests are not represented as my independent handwritten work or personal test execution.
